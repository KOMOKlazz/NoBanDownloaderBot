# Reposter Bot

Бот для Telegram: присылаешь ссылку на пост из TikTok, Instagram, Threads или YouTube
(или сам файл), а он присылает обратно фото и видео файлами (без пережатия Telegram),
с незаметной обработкой. Входить в аккаунты соцсетей не нужно.

## Что меняется в файле

| | Фото | Видео |
|---|---|---|
| Обрезка краёв 1–2,5% + масштаб обратно | ✅ | ✅ |
| Яркость / контраст / насыщенность ±1–3% | ✅ | ✅ |
| Едва заметная виньетка | ✅ | ✅ |
| Слабое зерно | ✅ | ✅ (меняется от кадра к кадру) |
| Ускорение 0–3% (тон голоса не меняется) | — | ✅ |
| Громкость ±4%, другая частота дискретизации | — | ✅ |
| Перекодировка, удаление EXIF и всех метаданных | ✅ | ✅ |

Все параметры случайные для каждого файла.

## Как бот скачивает

Бот пробует способы по очереди, пока какой-нибудь не сработает:
1. **yt-dlp**: видео, фото-посты и карусели Instagram (фото + видео), TikTok, YouTube.
2. **gallery-dl**: запасной вариант, например для фото-каруселей TikTok.
3. **og-теги страницы**: последний шанс, полезен для Threads. Даёт только одно фото или видео.

Если не сработало ничего, можно просто прислать боту фото или видео файлом.

## Установка (Windows)

1. Python 3.10+ и **ffmpeg** (должен быть в PATH):
   ```
   winget install Gyan.FFmpeg
   ```
2. Зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Создай бота у @BotFather, скопируй `.env.example` в `.env` и вставь токен.
4. Запусти `python bot.py`, отправь боту `/start`: он покажет твой ID. Впиши его
   в `ALLOWED_USERS`, чтобы ботом не пользовался никто, кроме тебя, и перезапусти бота.

## Лимиты 50 и 20 МБ

Через обычный Bot API бот может принять у тебя файл не больше 20 МБ.
Видео больше этого размера присылай ссылкой.

Отправить файл бот может не больше 50 МБ. Бот сам поднимает сжатие и при необходимости
уменьшает разрешение до 720p. Если и этого мало (длинные ролики с YouTube), запусти
[локальный Bot API сервер](https://github.com/tdlib/telegram-bot-api)
и пропиши `LOCAL_BOT_API_URL=http://localhost:8081`. Тогда лимит будет 2 ГБ.

## Если что-то перестало скачивать

Соцсети часто меняют свои сайты. Сначала обнови загрузчики, обычно это всё чинит:
```
pip install -U yt-dlp gallery-dl
```
Если соцсеть начала требовать вход (на сервере такое бывает с YouTube), экспортируй
cookies отдельного аккаунта расширением «Get cookies.txt LOCALLY» в `cookies.txt`
рядом с ботом и пропиши `COOKIES_FILE=cookies.txt`.
